# How To Run The Event Planner
Firstly run this intial command in the terminal: ```python event_planner.py``` <br>
You will then be asked to input the name of the file containing all the activities including the ".txt".<br>
After this, you will be prompted to input the constraints you will to put on the inputted activities with the following meanings:

- "T" - Time Constraint (1D algorithms)
- "B" - Budget Constraint (1D algorithms)
- "TB"- Time and Budget Constraint (2D algorithms)<br>

Then the program will run and output the result
